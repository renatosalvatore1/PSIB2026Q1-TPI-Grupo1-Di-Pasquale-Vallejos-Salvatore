# Cómo ejecutar nuestro proyecto:
Una vez instaladas las librerias necesarias, se debe ejecutar el codigo presente en "main.py". 
Luego de que se inicie la interfaz puede elegirse cualquiera de los estudios presentes en las carptas "sub-KAXX/anat" 
que finalicen en run-02_T1w.nii.gz dado que estos son los realizados en T1 post-contraste.
